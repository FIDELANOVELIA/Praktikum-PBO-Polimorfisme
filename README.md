# Praktikum PBO – Pertemuan 04
📚 Daftar Latihan

## Latihan 1 — Class & Object
Latihan awal untuk mengenal cara mendefinisikan class, membuat object, dan memanggil method. Bagian ini jadi pondasi buat latihan berikutnya.

## Latihan 2 — Constructor
Menunjukkan cara kasih nilai awal ke object lewat constructor. Jadi lebih rapi dan lebih aman dibanding set value satu-satu.

### Latihan 3 — Method dengan Parameter & Return
Mulai belajar method yang bisa menerima input dan menghasilkan output. Konsep dasar yang nanti sering dipakai di program lebih besar.

### Latihan 4 — Operasi Perhitungan
Berisi method sederhana buat operasi hitung dasar. Dipisah ke dalam beberapa method supaya alurnya lebih jelas dan mudah dicek.
